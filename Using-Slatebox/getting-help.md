# Getting help

Search first, then ask. Every question asked in the open helps the next person who has it.

## Search the docs

Type in the search box at the top of any page, or press `/` to jump to it. Results show as you type; press **Enter** to [see every result](/search/).

## Ask the community

Go to [support.slatebox.com](https://support.slatebox.com/). One search box looks through these docs and the community's questions at once. If nobody has asked yet, choose **Ask a question**.

The community runs on [GitHub Discussions](https://github.com/Slatebox/slatebox/discussions), so you post with a GitHub account. The people who build Slatebox answer there too. Mark the reply that solved your question so others find it.

| You want to | Go to |
| --- | --- |
| Ask how to do something | [Ask a question](https://github.com/Slatebox/slatebox/discussions/new?category=q-a) |
| Suggest a feature | [Share an idea](https://github.com/Slatebox/slatebox/discussions/new?category=ideas) |
| Report something that does not work | [Report a bug](https://github.com/Slatebox/slatebox/issues/new?template=bug_report.yml) |
| Ask about your account, a payment or conduct, in private | [Contact us](https://slatebox.com/contact/) |
| Report a security problem | [Our security policy](https://github.com/Slatebox/slatebox/blob/main/SECURITY.md), never a public post |

## From the app

Open the menu and choose **Help and support**. It opens these docs, the community, a bug report or the contact form. **Report a bug** fills in the app's version and your browser for you, and nothing else about you.

## Report a bug well

1. Say what you saw and what you expected instead.
2. List the steps that make it happen again.
3. Name where it happened: Slatebox Cloud, a self-hosted Slatebox (with its version), SlateboxJS in your app, or the MCP server.
4. Add a screenshot or the log lines. Remove keys, tokens and personal data first.
