    Getting help

    Read Markdown
    View agent prompt
    Help me complete my task in Slatebox using the official app guide. Ask which outcome I want, then walk me through the relevant steps and verify it on my slate.

Read https://docs.slatebox.com/Using-Slatebox/getting-help.md first. Ask for the inputs you need. Tell me what you verified and which steps I still need to do.

If your client cannot fetch the documentation, read the same published file at https://raw.githubusercontent.com/Slatebox/slatebox-docs/retype/Using-Slatebox/getting-help.md.

    Search first, then ask. Every question asked in the open helps the next person who has it.

    Search the docs

    Type in the search box at the top of any page, or press / to jump to it. Results show as you type; press Enter to see every result.

    Ask the community

    Go to support.slatebox.com. One search box looks through these docs and the community's questions at once. If nobody has asked yet, choose Ask a question.

    The community runs on GitHub Discussions, so you post with a GitHub account. The people who build Slatebox answer there too. Mark the reply that solved your question so others find it.

    From the app

    Open the menu and choose Help and support. It opens these docs, the community, a bug report or the contact form. Report a bug fills in the app's version and your browser for you, and nothing else about you.

    Report a bug well

    1. Say what you saw and what you expected instead.
    2. List the steps that make it happen again.
    3. Name where it happened: Slatebox Cloud, a self-hosted Slatebox (with its version), SlateboxJS in your app, or the MCP server.
    4. Add a screenshot or the log lines. Remove keys, tokens and personal data first.
