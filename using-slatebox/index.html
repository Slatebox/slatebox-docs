Slatebox user guide

Start your first slate

Choose Open a blank slate for a freeform canvas. Add a note for the decision, add one for the evidence, and connect them. Use Build an interactive map when participants should move an item along specific paths. Start a slate

Give your slate a recognizable name. If you began as a guest, register the guest account in that browser before relying on access from another device. Keep the canvas link. People opening a private link still need permission.

Turn a workshop into a decision

Open a workshop, try moving a card, then inspect the changed result. In a release plan, grouped moves can be previewed together before applying them. For a live session, choose Share live workshop and grant your teammate access. Use Present workshop to review the shared state, then return to editing. Open workshops

Work with a team

A team administrator can invite people through team settings. Once a teammate joins, use the slate or shared workshop's access controls to choose edit or view access. Open the same slate in each participant’s browser to see changes. A link to a private board alone does not invite someone into the team. Manage team members

Present or publish

Present your board when the group is ready to walk through a decision. For a public snapshot that can appear on another site, publish a presentation and use its published ID in an iframe. Sharing a snapshot and granting edit access serve different audiences. Embed a presentation

Choose where to work

Individuals can create unlimited slates on the free hosted plan. Pro adds AI capabilities. Team plans support a shared organization. Open the plan chooser for current features and billing options. Organizations with their own infrastructure can operate the app, relay and database together. Hosted plans · Self-host with Docker
